# 學號前綴查詢

課程標準頁提供依入學年度與學號前綴的候選清單。輸入完整年度（例如 `109`）後即載入該年度的系所建議；接著輸入一碼（`109a`）或兩碼（`109ab`）系所前綴，清單會逐步縮小。解析器接受民國 80–199 年格式，實際可查詢年度仍以 API 的年度清單為準。使用者選擇候選後才套用入學年度、學制與系所；不由第六碼推定學制，也不把 `division` 當成完整學號格式。

頁面以「快速搜尋」與「條件選擇」兩個頁籤切換查詢方式，預設開啟快速搜尋。條件選擇提供年度、學制與系所選單；切換頁籤保留已選條件與課程結果。

## 資料來源

官方課程標準的系所列表：

- `https://aps.ntut.edu.tw/course/tw/Cprog.jsp?format=-3&year=109&matric=7`
- 每個系所連結的 `division` 與 `matric`，搭配該頁系所名稱及學制名稱。

爬蟲輸出 `/{year}/standard-departments.json`：

```json
[
  { "system": "四技", "department": "資財系", "division": "AB0", "matric": "7" }
]
```

前兩碼相同的系所列為候選，因此分組與不同學制可能出現多筆；輸入一碼時則比對 `division` 的第一碼。未輸入系所碼時列出該年度所有正式學制的系所建議。這是課程系統代碼對照，並非個別學生的學籍驗證。年度與分組均以該年度的索引為準；不套用跨年度科系名稱。

## 相容性與隱私

- 輸入完整入學年度後下載該年度索引，成功資料快取一天；後續輸入系所前綴只在本地篩選。
- 未提供索引的年度顯示載入失敗與重試，仍可使用原有三個選單。
- 查詢網路請求只含年度；輸入內容不寫入網址、搜尋紀錄或 localStorage。
- 選擇結果後，網址與原有偏好儲存只包含年度、學制與系所。

## 維護

以爬蟲專案的系所索引指令更新年度 JSON，發布到原 API 位置。先更新並發布爬蟲索引，再部署新版前端。不手動維護學號與科系對照，也不提供前端快照備援。

```bash
# 在 ntut-course-crawler-node 執行，省略年度即更新所有年度索引
node fetchStandardDepartments.js
# 僅驗證特定年度
node fetchStandardDepartments.js 109 115
```

既有 `fetchStandards.js` 也會在爬取課程標準時同步產生索引，排程的發布 artifact 已包含 `dist/*/standard-departments.json`。

## 驗證

- 官方 109 年索引 244 筆、115 年 229 筆。
- `109` 先列出該年度正式學制的系所建議，`109a` 再依第一碼篩選，`109ab` 列出四技、碩士班、進修部四技的資財系候選；選四技後載入 109 年四技資財系課程。
- `10933` 列出材資系材料組、資源組；375px 手機清單無水平溢位。
- 自動測試涵蓋年度即查詢、一／兩碼前綴漸進篩選、兩／三位年度邊界、多學制／分組、API 失敗重試、只傳年度、快取，以及舊年度慢回應不覆蓋新選擇。

# 課程欄位盤點

查核日期：2026-09-13。範圍為爬蟲課程清單、個別課綱及前端課程詳情頁；清單卡片維持摘要，完整內容集中於詳情頁。

## 資料來源與範圍

- [學校課程系統](https://aps.ntut.edu.tw/course/tw/course.jsp)
- [官方課綱範例](https://aps.ntut.edu.tw/course/mobile/ShowSyllabus.jsp?snum=360744&code=23602)
- [115 年上學期日間部資料](https://gnehs.github.io/ntut-course-crawler-node/115/1/main.json)
- [課綱 JSON 範例](https://gnehs.github.io/ntut-course-crawler-node/115/1/course/360744.json)
- 爬蟲：`crawler/fetchCourse.js`、`crawler/fetchSyllabus.js`。

115/1 三部別清單合計 3,465 筆（跨部別會重複），共有 2,719 個課號；現行清單引用 2,295 筆教師課綱。新增三欄在這些課綱皆有輸出，但部分值僅為「無」。修改前 `ta` 與 `language` 在三部別清單全部為空。已確認 `language` 原本由爬蟲固定填入空字串，現改由官方表頭讀取；`ta` 則保留舊資料相容，不再誤讀新欄位。

## 課綱欄位

個別課綱 API 回傳教師課綱陣列，並非課程物件。多名教師可切換。

| 爬蟲欄位                     | 前端呈現與處理                                                                     |
| ---------------------------- | ---------------------------------------------------------------------------------- |
| `name`, `email`              | 已發布的教師與聯絡資訊；程式碼與測試不內嵌真實聯絡資料                             |
| `objective`                  | 課程大綱                                                                           |
| `schedule`                   | 課程進度                                                                           |
| `scorePolicy`                | 評量標準                                                                           |
| `materials`                  | 教材、參考書目                                                                     |
| `consultation`               | 課程諮詢管道                                                                       |
| `officeHoursLink`            | 教師諮商時間來源連結，僅接受 HTTP(S)，不顯示原始技術欄名                           |
| `remarks`                    | 課綱備註                                                                           |
| `延伸教學與資源`             | 原欄名及完整內容                                                                   |
| `課程對應SDGs指標`           | 原欄名及完整內容                                                                   |
| `課程是否導入AI`             | 原欄名及完整內容                                                                   |
| `foreignLanguageTextbooks`   | 僅明確為 true 時顯示；爬蟲 false 也可能是學校未填，因此隱藏，不能當作否            |
| `latestUpdate`               | 更新日期與相對時間；缺少時隱藏，無法解析時保留原文                                 |
| `covid19`                    | 僅保留舊課綱實際有填的資料；二級上課方式與說明各自呈現，不添加推測的一級／三級規定 |
| 未映射的文字、布林、數值欄位 | 使用學校原始欄名呈現，避免新增欄位再被靜默略過                                     |

課綱空白與精確占位值 `無`、`● 無 (None)`、`無（None）`、`● 無（None）` 隱藏；不以包含 `None` 等模糊比對方式刪除有實質內容的文字。數值 0、布林否不視為空值。未來若來源新增物件或陣列，需先確認語意再增加專屬顯示方式。

舊疫情欄位包含 `lv2Method`、`lv2Description`、`courseScoreMethod`、`courseInfo`、`courseURL`、`contactInfo`、`additionalInfo`，皆有對應顯示。現行課綱不額外放置疫情空區塊。

## 已確認的資料品質問題

- 外文原文書的 false 並非可信的否：爬蟲以是否匹配「使用外文原文書：是」推算，學校未填也輸出 false。官方課號 360744 可驗證此情況；前端隱藏未明確回答的資訊，本次已將爬蟲改為是／否／未填三態；前端仍只顯示明確 true，以相容既有 false 語意。

- 退選率 API 值為數字字串，前端原型別寫成數字；已修正型別與轉換，區分 0% 和沒有資料。教師退選率由課程教師取得，不依賴課綱是否抓取成功。
- 原本課綱或退選率任一 API 失敗會阻止整頁顯示；改為保留課程主資料，課綱失敗另顯示提示及可用的原始連結。
- 發布目錄保留舊檔：115/1 有 16 個有內容的課綱檔不再被現行清單引用，其中 10 個採用 `課程進度(1-16週)`／`彈性學習(17-18週)` 格式。不能將目錄內檔案總量當成目前開課數。本次發布流程先驗證三部別清單與所有引用課綱，再以完整快照替換該學期課綱目錄；未通過驗證不發布。所有推送 gh-pages 的工作共用發布佇列，避免同時推送互相覆蓋；採用 [GitHub 官方 concurrency／queue 設定](https://docs.github.com/en/actions/how-tos/write-workflows/choose-when-workflows-run/control-workflow-concurrency)，不取消正在執行或已排隊的工作。
- 上述替代表格的 `類別`、`內容`、`時數(小時)`、`學習成果`、`評量比例` 也可在有值時呈現。這次盤點沒有確認到目前開課清單正在使用該格式，不推論它已全面上線。

## 驗證重點

最容易失效的情況是：有效 0／false 被誤當空值、學校新增表頭、空白或缺少日期、附屬 API 失敗，以及相對／不安全的來源連結。整合測試使用假資料覆蓋這些邊界，並以現行課號 360744 檢查真實資料與手機版寬度。

## 本次補齊的功能與資料

- **授課語言與課程屬性：** 爬蟲按官方 QueryCourse 表頭解析授課語言、隨班附讀、實驗實習、跨領域，不再依賴舊助教欄的位置；前端加入語言與屬性篩選，首頁提供英語授課捷徑。
- **教師諮商時間：** 保留 mobile 課綱教師旁的 Office Hours 連結，課程詳情依是否有資料顯示。[官方課綱範例](https://aps.ntut.edu.tw/course/mobile/ShowSyllabus.jsp?snum=360748&code=12567)。
- **一般學程：** 新增 `/{year}/{sem}/programs.json`、`/program` 與學程詳情，可搜尋、查看跨部別課程及批次加入／移除我的課程。實測官方 115/1 有 16 個學程、224 筆課程項目、199 個不重複課號，全部可在三部別聯集找到。[官方一般學程](https://aps.ntut.edu.tw/course/tw/SearchProgram.jsp?format=-1&year=115&sem=1)。
- **核心能力：** 新增 `/competencies.json` 與 `/competencies`，依系所呈現課程、能力指標與對照，支援文字搜尋及查找開課。此來源沒有學期版本，不能當作畢業資格認定。官方入口有 37 個系所；機械系代表矩陣有 8 項能力、115 門課。[官方核心能力矩陣](https://aps.ntut.edu.tw/course/tw/CurrCCI.jsp?code=30&format=-2)。
- **AI／SDGs：** 爬蟲建立 `/{year}/{sem}/syllabus-index.json`，合併同課號多教師課綱的 AI 教學方式、SDG 1–17 與延伸資源。搜尋僅讀索引，不逐筆下載課綱；索引缺少時提示未提供，不把它解讀為沒有導入 AI。
- **教室使用明細：** 空教室頁依三部別課程呈現各節實際課名、詳情連結，同課號去重，同節多課完整保留。仍依課表推算，不保證臨時借用、考試或其他活動占用；官方教室原頁可直接查看。

## 發布與相容性

新增 API 尚未發布時，頁面會明確提示資料未提供，404 不寫入快取。一般學程隨既有微學程排程更新，核心能力隨課程標準更新，課綱索引與課程排程一併產生。需執行新版爬蟲並發布資料，線上網站才會取得新欄位；本次沒有部署或啟動完整學期爬取。

課程詳情會在目前部別找不到課號時查找其他部別，收藏寫入實際課程所屬學期與部別。一般學程批次收藏與個別課程按鈕同步，避免 UI 顯示與儲存內容不一致。

## 查核邊界

官方教室 `Croom.jsp` 另有容量、日間／夜間／週末使用節數與使用率；本次提供原頁入口，尚未建立這些統計的獨立 API。教師諮商時間提供官方連結，未複製整張諮商時段表。新能力矩陣與學程依官方內容呈現，不推算修業資格或畢業完成度。

## 完整資料驗證

以既有下載的 115/1 三部別與課綱，在獨立暫存目錄執行 `prepareCoursePublish` 與 `buildSyllabusIndex`：2,719 個唯一課號皆通過課綱數量驗證，產生同數索引；1,478 門有 AI 項目、1,750 門有 SDGs。共 64 個不再被清單引用的檔案（包含空檔）排除於快照，來源目錄未修改。這是已下載資料的整合驗證，不代表重新爬取全部課綱或完成線上發布。

## 對抗式審查案例

1. **抓取不完整卻刪除舊檔：** 缺任一部別清單、缺課綱或教師課綱數量不足時，發布快照建置會失敗。清理只針對已驗證學期，不改其他資料目錄。
2. **重跑保留舊教師／舊課號：** 每門課的課綱以本次抓取結果覆寫；索引只遍歷現行課號，沒有課綱連結時忽略殘留 JSON。
3. **有效資料無匹配卻顯示全部：** AI／SDGs 索引存在時，空索引或無匹配值回傳零筆。只有資料來源未提供或失敗時，才提示條件未套用。
4. **跨部別收藏寫錯位置：** 學程、詳情與課程清單測試檢查實際年度／學期／部別參數；手機操作驗證批次與單筆收藏同步。
5. **空值、錯誤日期或來源連結破壞詳情：** 測試保留有效 0／false、隱藏精確占位值、不依賴課綱 API 成功，並拒絕非 HTTP(S) 連結。

最終驗證：前端 118 項測試、TypeScript 型別檢查與正式建置通過；爬蟲 28 項測試、五個發布工作的共用佇列與 YAML 檢查通過。微學程也補上登入／錯誤頁辨識，確認明細抓取失敗不覆蓋既有清單；實測官方入口 49 個微學程、AV2 明細 32 個不重複課號。
